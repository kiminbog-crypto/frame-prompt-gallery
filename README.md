# FRAME — 이미지·프롬프트 갤러리

이 대화에서 만든 이미지와 생성 프롬프트를 함께 보관하는 공개 갤러리입니다. 웹사이트는 감상·검색·프롬프트 복사에 사용하며, 등록은 연결된 GitHub 저장소를 통해 이 대화의 Codex가 수행합니다.

## 등록 방법

1. 이 대화에서 이미지를 생성합니다.
2. “방금 만든 이미지를 갤러리에 올려줘”라고 요청합니다. 여러 장이면 대상 이미지를 지정합니다.
3. Codex가 이미지 파일을 `images/`에, 제목·태그·영어 프롬프트·한글 프롬프트를 `data/entries.json`에 커밋합니다.
4. GitHub Pages가 자동 배포되면 갤러리에서 이미지와 프롬프트를 확인합니다.

이전 대화의 이미지라면 이미지를 이 대화에 첨부하거나 정확한 파일을 지정하세요. 생성 프롬프트가 대화에서 확인되지 않으면 등록 전에 해당 문구를 제공해야 합니다. 이미지를 만들었다는 사실만으로 자동 게시되지는 않으며, “올려줘” 요청이 있어야 게시됩니다.

## 웹페이지

- [갤러리 바로가기](https://kiminbog-crypto.github.io/frame-prompt-gallery/)
- GitHub 저장소 오른쪽 **About**의 웹사이트 링크를 눌러도 됩니다.

## 데이터 형식

`data/entries.json`은 배열이며 각 항목은 `id`, `title`, `promptEn`, `promptKo`, `note`, `tags`, `image`, `aspectRatio`, `createdAt`으로 구성됩니다. `image`는 `images/파일명.png` 같은 상대 경로입니다. 생성에 사용한 원문 프롬프트와 다른 언어로 번역한 프롬프트를 각각 보관합니다. 프롬프트와 이미지는 공개 저장소에 저장되어 누구나 볼 수 있습니다.

## 배포

`.github/workflows/pages.yml`이 `main` 브랜치 변경 시 정적 사이트를 GitHub Pages에 게시합니다.
